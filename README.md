## NeoForge版で遊べること

専用BOT練習場でRX-78-2を装備し、ブースト移動、ビーム・ライフル、盾、ハイパー・ハンマー、スーパーナパームを使えます。ソロでの訓練に加え、LANでは二人で対戦したり、ピンで位置を知らせて中破した味方をリペアしたりできます。
