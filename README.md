『GUNDAM EVOLUTION』の非公式ファンMODです。

## 対応環境

- Minecraft 1.21.1／NeoForge 21.1.265／Java 21
  - [0.4.0-alpha.1 のJARをダウンロード](https://github.com/NPJigaK/gunevo-minecraft/raw/refs/heads/main/gunevo-neoforge-mc1.21.1-0.4.0-alpha.1.jar)
- Minecraft 1.20.1／Forge 47.2.18／Java 17
  - [JARをダウンロード](https://github.com/NPJigaK/gunevo-minecraft/raw/refs/heads/main/gunevo-forge-mc1.20.1-0.0.1-alpha.1.jar)

ダウンロードしたJARを、対応するMinecraftプロファイルの `mods` フォルダに入れてください。
